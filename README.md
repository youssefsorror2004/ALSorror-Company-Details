# Comprehensive Enterprise Business Intelligence Suite

An end-to-end, 5-page interactive Power BI dashboard suite designed for executive-level decision making.

## Project Overview
This project delivers a 360-degree operational analysis integrating multiple enterprise domains into a unified reporting system:
- **Sales & Financials:** Tracking revenue, profit margins, and monthly growth trends.
- **HR Analytics:** Evaluating workforce distribution, salary benchmarks, and retention metrics.
- **Supply Chain & Logistics:** Analyzing shipping performance and distribution operations.
- **Customer & Market Analysis:** Segmenting customer markets and geographic spread.
- **Product & Sales Analysis:** Identifying top-performing categories, products, and sales volumes.

## Built With
- **Business Intelligence Tool:** Microsoft Power BI Desktop
- **Data Modeling:** Star Schema / Relational Data Model
- **Calculations & KPIs:** DAX (Data Analysis Expressions)

## How to View & Explore
1. Clone or download this repository.
2. Ensure you have **Microsoft Power BI Desktop** installed.
3. Open the `.pbix` file locally to interact with all dynamic visuals, cross-filtering, and slicers.
